# Rasel Bornali — Unicode Bangla Font

**Rasel Bornali** একটি আধুনিক ও কাস্টম-ডিজাইন করা বাংলা ইউনিকোড (Unicode) ফন্ট। এটি ক্লাসিক বাংলা টাইপোগ্রাফির সৌন্দর্য এবং আধুনিক ডিজিটাল টাইপিংয়ের সুবিধাকে একত্রিত করে তৈরি করা হয়েছে। ফন্টটির ডিজাইন মূলত জনপ্রিয় ANSI ফন্টের স্টাইল ও সৌন্দর্য থেকে অনুপ্রাণিত।

## ✨ Features
- **Unicode Support:** আধুনিক ওয়েব, মোবাইল অ্যাপ এবং সফটওয়্যারে সরাসরি ব্যবহারের উপযোগী।
- **Classic Aesthetic:** জনপ্রিয় ANSI ফন্টের ক্লাসিক লুক এবং পঠনযোগ্যতা বজায় রাখা হয়েছে।
- **Optimized Glyphs:** বাংলা অক্ষর, যুক্তাক্ষর এবং কার-চিহ্নের জন্য কাস্টম স্পেসিং ও কার্নিং (Kerning)।
- **Versatile Usage:** ওয়েব ডিজাইন, প্রিন্ট মিডিয়া, লোগো এবং ডিজিটাল কন্টেন্টের জন্য উপযুক্ত।

## 🛠️ How to Install
1. রিপোজিটরি থেকে `RaselBornali-Regular.ttf` (বা `.otf`) ফাইলটি ডাউনলোড করুন।
2. ফাইলটিতে ডাবল ক্লিক করুন এবং **"Install"** বাটনে ক্লিক করুন।
3. যেকোনো টেক্সট এডিটর, গ্রাফিক ডিজাইন সফটওয়্যার বা ওয়েব প্রজেক্টে `Rasel Bornali` সিলেক্ট করে ব্যবহার শুরু করুন।
